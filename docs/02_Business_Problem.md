# Business Problem Formulation and ML Transformation

Before building models, we must translate abstract business requirements into concrete, mathematically defined Machine Learning tasks. 

---

## 1. Domain Context: E-Commerce Retail
We are designing this platform for a non-contractual business model (e-commerce). Unlike subscription businesses (e.g., Netflix, SaaS) where churn is explicitly defined by cancellation events, customers in retail simply stop buying. This introduces ambiguity in formulating targets, requiring strict operational thresholds.

---

## 2. ML Formulations

### Module A: Customer Churn Prediction
* **Business Goal:** Identify customers likely to abandon the platform so marketing can send retention offers.
* **ML Task:** **Binary Classification**.
* **Target Definition ($y$):** 
  $$y_i = \begin{cases} 
  1 & \text{if customer } i \text{ makes } 0 \text{ transactions in the observation window } [T, T + 90\text{ days}] \\
  0 & \text{otherwise} 
  \end{cases}$$
* **Lookback Window:** Behavioral history evaluated in $[T - 180\text{ days}, T]$.
* **Core Model Candidates:** XGBoost, LightGBM, CatBoost.

### Module B: Customer Lifetime Value (CLV) Prediction
* **Business Goal:** Allocate marketing budgets (Customer Acquisition Cost - CAC) efficiently by identifying high-value customers early.
* **ML Task:** **Regression**.
* **Target Definition ($y$):** 
  $$y_i = \sum_{t = T}^{T + 365\text{ days}} \text{Net Revenue}(i, t)$$
  Predict the continuous dollar value generated by customer $i$ over a 12-month forward horizon.
* **Core Model Candidates:** Ridge Regression, ElasticNet, Random Forest Regressor, LightGBM Regressor.

### Module C: Customer Segmentation
* **Business Goal:** Group customers automatically based on value and engagement styles for tailored marketing campaigns.
* **ML Task:** **Unsupervised Clustering**.
* **Input Representation:** Recency, Frequency, and Monetary (RFM) vectors:
  $$\mathbf{x}_i = [R_i, F_i, M_i]^T$$
* **Core Model Candidates:** KMeans (with Elbow/Silhouette analysis for $K$), DBSCAN (for density-based distribution), Hierarchical Clustering (for cohort taxonomy).

### Module D: Recommender System
* **Business Goal:** Drive cross-selling and upselling by displaying relevant products.
* **ML Task:** **Hybrid Collaborative & Content-Based Recommendation**.
* **Target Definition:** Rank items $j$ for user $i$ by predicted interaction score/probability:
  $$\hat{r}_{ij} = f(\mathbf{u}_i, \mathbf{v}_j)$$
* **Core Model Candidates:** Matrix Factorization (SVD), Cosine/Jaccard Similarity, or LightFM hybrid architecture.
